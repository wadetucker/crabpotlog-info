# CrabPotLog information

Static support information for CrabPotLog, with no site-added tracking scripts or dependencies.

The single canonical Privacy Policy is **https://crabpotlog.com.au/privacy-policy**. The GitHub Pages privacy page links to that website; it is not a second policy.

Current iPhone app analytics behavior: dedicated first-party Firebase Analytics Core defaults on for new installs/missing preferences, preserves previous explicit opt-outs, and has no analytics setting or consent prompt in More. Apple Watch has no analytics. Privacy Policy and Contact Support remain accessible in More. The canonical website already discloses iPhone Analytics without optional/off-default wording (checked 5 October 2026). App Store privacy disclosure remains owner-confirmed separately; this repository does not attest compliance.

GitHub Pages: publish the main branch root. The GoDaddy website has separate hosting/cookie notices; this static site's lack of scripts makes no claim about GoDaddy.
